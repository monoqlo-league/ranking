# MONOQLO PTランキング

雀魂 MONOQLO の対局記録(CSV)から、シーズン(月)ごとのPTランキング、通算ランキング、対戦相性表を表示するページ。
ページを開くたびに、リポジトリにある月ごとのCSVを読み込んで集計する。

## ファイル名のルール

CSVは **1シーズン(1か月)につき1ファイル**、名前は **年4桁+月2桁.csv** にする。

| シーズン | ファイル名 |
|---|---|
| 2026年9月 | `202609.csv` |
| 2026年10月 | `202610.csv` |
| 2027年1月 | `202701.csv` |

- 「今月のランキング」には、いちばん新しい月のファイルが表示される。
- 「通算ランキング」は、すべての月のファイルを合計したもの。
- 名前がルールと違うファイルは読み込まれない。

## ランキングの更新手順(更新担当者向け)

1. 雀魂の大会管理画面から、そのシーズンの対局記録のCSVを書き出す。
2. ファイル名を、そのシーズンの **`年月.csv`**(例: `202610.csv`)に変える。
3. このリポジトリのページ上部にある **「Add file」→「Upload files」** を押す。
4. CSVを画面にドラッグ&ドロップする。同じ名前のファイルがあれば上書きされる。
5. 下の **「Commit changes」** を押す。
6. 1〜2分待ってから、ランキングのページを再読み込みする。

シーズン途中で何度更新してもよい。同じ月のファイルを、その時点までの全対局が入ったCSVで上書きする。

### 注意

- 前の月のファイルは消さない。消すと、過去のランキングと通算成績からその月が消える。
- 「非表示状態」が yes の対局は集計に含めない。
- 同じ対局(同じ牌譜)が2つの月のファイルに入っていても、通算では1回だけ数える。
- 間違ったファイルを上げてしまっても、そのファイルを開いて「History」から前の版に戻せる。困ったら管理者に連絡する。
- 数分たっても変わらないときは、ブラウザの再読み込み(スマホなら一度タブを閉じて開き直す)を試す。

## ファイル

- `index.html` … ランキングのページ本体。置かれた年月CSVを自動で見つけて読み込む(一番古い月から最新の月まで)
- `YYYYMM.csv` … 各シーズンの対局記録
