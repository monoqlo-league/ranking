# MONOQLO PTランキング

雀魂 MONOQLO の対局記録(CSV)から、合計PT順のランキングと対戦相性表を表示するページ。
ページは `data.csv` を読み込んで、開くたびに集計する。

## ランキングの更新手順(更新担当者向け)

1. 雀魂の大会管理画面から、対局記録のCSVを書き出す。
2. 書き出したファイルの名前を **`data.csv`** に変える(名前が違うと反映されない)。
3. このリポジトリのページ上部にある **「Add file」→「Upload files」** を押す。
4. `data.csv` を画面にドラッグ&ドロップする。
5. 下の **「Commit changes」** を押す。
6. 1〜2分待ってから、ランキングのページを再読み込みする。

### 注意

- CSVは毎回、集計したい期間の対局がすべて入ったものを上げる。前のデータに足されるのではなく、丸ごと置き換わる。
- 「非表示状態」が yes の対局は集計に含めない。
- 間違ったファイルを上げてしまっても、`data.csv` を開いて「History」から前の版に戻せる。困ったら管理者に連絡する。
- 数分たっても変わらないときは、ブラウザの再読み込み(スマホなら一度タブを閉じて開き直す)を試す。

## ファイル

- `index.html` … ランキングのページ本体
- `data.csv` … 集計元の対局記録
