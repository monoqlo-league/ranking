# MONOQLO PTランキング

雀魂 MONOQLO の対局記録(CSV)から、シーズン(月)ごとのPTランキング、通算ランキング、対戦相性表を表示するページ。
ページを開くたびに、リポジトリにある月ごとのCSVを読み込んで集計する。

## ファイル名のルール

CSVは **1シーズン(1か月)につき1ファイル**、名前は **年4桁+月2桁.csv** にする。

| シーズン | ファイル名 |
|---|---|
| 2026年9月 | `202609.csv` |
| 2026年10月 | `202610.csv` |
| 2027年1月 | `202701.csv` |

- 「今月のランキング」には、いちばん新しい月のファイルが表示される。
- 「通算ランキング」は、すべての月のファイルを合計したもの。
- 名前がルールと違うファイルは読み込まれない。

## ランキングの更新手順(更新担当者向け)

### ランキングページからアップロードする(おすすめ)

1. 雀魂の大会管理画面から、そのシーズンの対局記録のCSVを書き出す(ファイル名はそのままでよい)。
2. ランキングページの一番下「CSVをアップロード」で **「CSVファイルを選ぶ」** を押し、CSVを選ぶ。
3. 期間・対局数と **「保存する月」** を確かめる(対局日時から自動で決まる)。
4. **合言葉** を入れて **「アップロードする」** を押す。
5. 「保存した」と出れば完了。ほかの人の画面には1〜2分後に反映される。

### GitHubから直接アップロードする(予備の方法)

1. ファイル名を、そのシーズンの **`年月.csv`**(例: `202610.csv`)に変える。
2. このリポジトリのページ上部にある **「Add file」→「Upload files」** を押す。
3. CSVを画面にドラッグ&ドロップし、**「Commit changes」** を押す。

シーズン途中で何度更新してもよい。同じ月のファイルを、その時点までの全対局が入ったCSVで上書きする。

### 注意

- 前の月のファイルは消さない。消すと、過去のランキングと通算成績からその月が消える。
- 「非表示状態」が yes の対局は集計に含めない。
- 同じ対局(同じ牌譜)が2つの月のファイルに入っていても、通算では1回だけ数える。
- 間違ったファイルを上げてしまっても、そのファイルを開いて「History」から前の版に戻せる。困ったら管理者に連絡する。
- 数分たっても変わらないときは、ブラウザの再読み込み(スマホなら一度タブを閉じて開き直す)を試す。

## 管理者向け: アップロード鍵の設定

ページからのアップロードには、GitHubのアクセストークンを合言葉で暗号化した `upload-key.json` を使う。

1. GitHub右上のアイコン →「Settings」→ 左下「Developer settings」→「Personal access tokens」→「Fine-grained tokens」→「Generate new token」。
2. 名前(例: ranking-upload)と有効期限を決める。
3. 「Repository access」で **Only select repositories** を選び、このリポジトリだけを指定する。
4. 「Permissions」→「Repository permissions」→ **Contents** を **Read and write** にする(ほかは触らない)。
5. 「Generate token」を押し、表示された `github_pat_…` をコピーする(画面を閉じると二度と見られない)。
6. 手元の `key-setup.html` をブラウザで開き、トークンと合言葉を入れて `upload-key.json` を作る。
7. `upload-key.json` をこのリポジトリにアップロードする。
8. 合言葉を更新担当者に伝える。

- 合言葉は単語を3〜4個つないだ16文字以上にする。短いと、鍵ファイルを持ち出した人に総当たりで破られる。
- トークンの期限が切れたら、1〜7をやり直して `upload-key.json` を上書きする。合言葉を変えるときも同じ。
- 万一合言葉が漏れたら、GitHubの設定画面でそのトークンを削除(Revoke)すれば、以後は書き込めなくなる。

## ファイル

- `index.html` … ランキングのページ本体。置かれた年月CSVを自動で見つけて読み込む(一番古い月から最新の月まで)
- `YYYYMM.csv` … 各シーズンの対局記録
- `upload-key.json` … 暗号化したアップロード用の鍵(管理者が作成)
- `key-setup.html` … 鍵ファイルを作る道具(リポジトリに置かなくてもよい)
