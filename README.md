# MONOQLO PTランキング

ページ: https://monoqlo-league.github.io/ranking/

MONOQLO麻雀部 PTランキングのページ本体(`index.html`)を置くリポジトリ。管理者だけが更新する。

- ページのいちばん上に、チーム戦ランキング(event-ranking)への切り替えがある。チーム戦ランキング側にも、このページへの切り替えがある。
- プレイヤー名を押すと、成績・相性表が開く。中身は上から、入賞記録・戦績・相性表。
  - **戦績**: そのプレイヤーの対局を新しい順に並べた一覧。1局につき1行で、日付のあとに、1位から4位まで全員の名前・終了時の点棒・獲得PTを並べる。そのプレイヤーの欄には色を付ける。表示している月(または通算)の対局が対象。ほかの人の名前を押すと、その人の成績に切り替わる。
  - 終了時点棒は、対局記録CSVの「N位PT」の列の値。
  - **相性表**: 見出しの横の「?」を押すと、各列の意味・並び順・対象の範囲・読むときの注意が開く。もう一度押すと閉じる。
- 集計元のデータ(月ごとの対局記録CSVと `ban.csv`)は、別リポジトリ **monoqlo-data** に置く。CSVの更新手順や集計のルールは、そちらの README を参照。
- ページは開くたびに monoqlo-data のファイルを読み込んで集計する。
- データ用リポジトリの名前を変えた場合は、`index.html` の `const DATA_REPO="monoqlo-data";` も同じ名前に書き換える。
